# 太乙神数 · 时计八门王希明法（P4-a）设计

> 日期：2026-07-26。范围：修正时计直使门算法（现误用年计 mod240÷30 八门公式）。
> 依据：《太乙金镜式经》卷一（Kanripo 四库文渊阁本 KR3g0047_001 逐字核对）。

## 1. 背景与原文裁定

卷一涉及时计八门的三处原文：

1. **「推八門用法」（张良）**：阳遁冬至甲日夜半甲子以后开门直使、丙日日中甲午以后生门、己日夜半甲子以后惊门、辛日日中甲午以后休门，三十时移门；阴遁夏至起杜/死/伤/景同法。
2. **「推八門用法」（王希明注）**：「臣今太乙冬至夏至初临之时，门则随数起，时尽则移，不拘其甲丙己辛日也。阳遁四门开生惊休，阴遁四门杜死伤景。」——明言以计算法取代张良锚日法。
3. **「推冬至加時所直門法」**：置天正时实，mod 240 → mod 120 → ÷30 为门数，命起开门以次而行。「推夏至加時所直門法」同法但「为门数（阙）而行之」有阙文。

**裁定结论（三说实为一体）**：

- 门池：阳遁 `[开,生,惊,休]`、阴遁 `[杜,死,伤,景]`（张良时序 = 王希明四门序，原文一致）。"以次而行" 指该四门时序，**非**八门自然序（开休生伤…）——此前"计算法得开/休/生/伤"系误读。
- 求法：王希明计算法（门随数起，不拘甲丙己辛日），即 `门数 = 时实 mod 120 ÷ 30`。
- 阙文填补：夏至法依王希明阴遁四门序补「命起杜门以次而行」，无歧义。
- 年计八门不动：现行 `积年 mod 240 ÷ 30`（八门自然序）正合卷一「推八門占嵗計法」（命起开门以次休生门；开元十二年甲子开门、三十一年甲午休门锚 ✓）。

**阴遁相位口径（用户裁定）**：两遁共用连续绝对积时（suanBase）同轨，仅换门池；**不**加卷一「夏至加时实」的 +2192 平气偏移——与 app 太乙宫连续积时口径一致（2024-10-09 阴遁1局锚点即按此验证）。因此阴遁无需新增夏至时实计算。

## 2. 算法

`TaiyiCalculator.computeZhiShiMen(suanBase, dun, type)`：

- **时计（HOUR）**：`门数 = floorMod(suanBase, 120) / 30`（0..3）；阳遁取池 `[开,生,惊,休]`、阴遁取池 `[杜,死,伤,景]`。
- **年计（YEAR）**：不变，`floorMod(积年, 240) / 30` → `TaiyiMen.order`（开休生伤杜景死惊）。
- 月计/日计：仍为 TODO（不在本范围）。

不变的部分：`computeMenOnTaiyi`（直使飞加太乙宫、八门自然序顺布）、`执提`格局（开门直使+太乙巽9 / 生门直使+太乙坤7）、`TaiyiPlate.zhiShiMen` 模型字段、UI 显示。

## 3. 代码改动（方案 A，最小改动）

- `TaiyiMen`：增 `poolYang = [开,生,惊,休]`、`poolYin = [杜,死,伤,景]` 两个常量。
- `TaiyiCalculator.computeZhiShiMen`：签名加 `dun: TaiyiDun`；HOUR 分支改为 mod 120÷30 + 按遁取池；YEAR 分支原样。调用点（`build`）透传 `ju.dun`。
- 注释注明：王希明改法（门随数起，不拘甲丙己辛日）、阙文填补依据、阴遁连续积时口径为用户裁定。

预计改动 ≈15 行主代码。

## 4. 测试锚点（无实盘古例，用结构锚点）

- **2023-12-22 冬至日子时（阳遁）**：绝对积时 137185080 = 1143209×120，mod 120 = 0 → 门数 0 → **开门**。
- **四门轮转**：冬至后 +30/+60/+90/+120 时辰 → 生/惊/休/开（30时一移、120时一周）。
- **2024-10-09 子时（阴遁）**：suanBase mod 120 = 24 → 门数 0 → **杜门**。
- **回归**：2024 年计 → 伤门不变；既有 27+ 太乙测试与全量 116+ 测试无回归。
