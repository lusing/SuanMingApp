# 太乙神数 · 四神三元五纪立成（P4-b）设计

> 日期：2026-07-26。范围：四神/天乙/地乙/直符四星神改按《太乙金镜式经》卷五「四神三元五纪立成」规则；新增地乙；修正 P3 两处偏差。
> 依据：Kanripo 四库文渊阁本 KR3g0047_005（卷五）逐字核对：推四神/天乙/直符太乙法正文 + 立成表 180 格。

## 1. 原文依据

**推法正文**（卷五）：
- 四神：「置上元甲子所求积年，以一百八十去之，不尽以三十六除之为纪数，不满算外为入纪来年数……置入纪年以三除之为宫数，不满为入宫以来年数，命起一宫顺行尽九宫，又以绛宫、明堂、玉堂接之。」五纪：第一甲子、第二庚子、第三丙子、第四壬子、第五戊子。
- 天乙：「置入纪年与四神同，以三除之为宫数……命起六宫顺行尽九宫又以三宫接之。」
- 直符：「命起五宫顺行尽九宫又以三宫接之。」
- 地乙：推地乙太乙法正文四库本已佚（目录存目），起例由立成表坐实（起九宫）。

**立成表**（60 太岁 × 4 神 × 三元，逐格验证）：
- 四神共用一条 **12 位环** `[1,2,3,4,5,6,7,8,9,绛,明,玉]`，仅起点不同：四神起 1、天乙起 6、地乙起 9、直符起 5。
- 相位：太岁三年一组同宫（甲子/乙丑/丙寅同值），决定 step 用 **（积年−1）**。
- 180 格中 160 格与统一公式全合；**直符·中元列 20 格**印作 `1..9,1..9,绛,明`，与推法正文、统一公式及其余 11 个列块全部矛盾——四库本抄刻疑讹，按统一公式实现（用户裁定 2026-07-26），文档注明。

## 2. 算法

积年 `J = year + 10153917`（与全局一致）。

```
step   = floorMod(J - 1, 36) / 3            // 0..11
pos(g) = CYCLE12[(offset(g) + step) mod 12] // CYCLE12 = [1..9, 绛, 明, 玉]
offset:  四神=0  天乙=5  地乙=8  直符=4
入宫年  = floorMod(J - 1, 3) + 1            // 1..3
元      = floorMod(J - 1, 180) / 60         // 上元/中元/下元
纪      = floorMod(J - 1, 180) / 36         // 甲子/庚子/丙子/壬子/戊子 纪
```

- 落 1..9 → palaceNo=宫号、location="卦X宫"；落三堂 → palaceNo=null、location="绛宫/明堂/玉堂"（沿现有处理）。
- 占义：四神 半吉（水神·纪纲有道则昌）；天乙 凶（金神主兵革）；地乙 凶（孤立无援，通行占义——四库本正文佚）；直符 凶（火神·值日巡察）。注记格式：`"<占义>·<元>·<纪>纪"`，如「金神主兵革·下元·戊子纪」。

## 3. 对 P3 实现的两处修正

1. **天乙/直符环序**：P3 误作「起 X 宫→顺尽九宫（1..9 环绕）→接三堂」（如天乙 6,7,8,9,1,2,3,4,5,绛,明,玉）；立成表证实三堂接在 9 宫之后再绕回 1（天乙 6,7,8,9,绛,明,玉,1..5）。例：2024 天乙 离2宫→**明堂**、直符 乾1宫→**绛宫**。
2. **相位 off-by-one**：step 由积年改（积年−1）。影响积年 ≡ 0 mod 3 的年份，如 1998 四神 绛宫→**9宫**（P3 该测试值系按实现反推，本身即误）；入宫年亦随之修正（2024：3→2）。

同时更正出处标注：四神诸神推法在**卷五**（P3 注释误记卷四）。
