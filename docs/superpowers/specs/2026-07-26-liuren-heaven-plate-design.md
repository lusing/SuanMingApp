# 大六壬天地盘十二宫方盘设计

**日期：** 2026-07-26

## 目标

为现有大六壬排盘页补充天地盘十二宫方盘，使用户能够直观看到天盘相对地盘的旋转关系及十二天将的实际落宫。现有四课、三传和毕法赋功能保持不变。

## 页面结构

起课结果按以下顺序展示：

1. 课盘摘要
2. 天地盘十二宫方盘
3. 四课
4. 三传
5. 毕法赋

方盘已经完整呈现十二天将及其落宫，因此删除原有“十二天将所临”标题和标签列表，避免重复信息。

## 方盘布局

方盘采用传统方位，固定为上南下北。外围十二地盘位排列如下：

```text
       巳   午   未   申
       辰             酉
       卯             戌
       寅   丑   子   亥
```

在 Compose 中可用 4×4 网格实现；中央四格合并为视觉上的中央区域，外围十二格对应十二地支。

每个宫位从上到下显示：

- 地盘支：小号灰色文字；
- 天盘支：大号粗体文字，沿用项目现有五行颜色；
- 天将：小号文字，吉将绿色、凶将红色。

中央区域显示：

- 月将专名及对应地支；
- 占时地支；
- “上南下北”方位提示。

布局宽度跟随页面宽度，各宫等宽。字体和间距以窄屏真机上不截断、不横向溢出为底线，不增加横向滚动。

## 组件与职责

新增独立 Compose 组件 `LiurenHeavenPlate`，文件位于：

`app/src/main/java/cn/xulun/bazi/ui/components/LiurenHeavenPlate.kt`

组件只接收现有 `LiuRenPlate`，负责把已有排盘数据转换为方盘视图：

- 根据固定地盘方位顺序绘制外围十二宫；
- 调用 `plate.heavenAt(earthBranch)` 获取指定地盘位上方的天盘支；
- 从 `plate.tianJiang` 中按 `earthBranch` 查找落在该地盘位的天将；
- 应用现有主题色、五行色及天将吉凶色。

组件不计算月将、天盘偏移、四课、三传或天将布法，避免 UI 重复业务算法。

## 数据流

数据流保持单向：

```text
LiurenPage.generate()
  → LiuRenCalculator.buildPlate()
  → LiuRenPlate
  → LiurenHeavenPlate(plate)
      ├─ plate.heavenAt(地盘支)
      └─ plate.tianJiang 按 earthBranch 查找天将
```

现有 `LiuRenPlate.tianPanOffset`、`heavenAt()` 和 `TianJiangOnPlate.earthBranch` 已足以支持方盘，不修改算法和数据模型。

## 页面集成与清理

在 `LiurenPage` 的课盘摘要之后、四课之前加入“天地盘（上南下北）”标题和 `LiurenHeavenPlate`。

同时移除：

- “十二天将所临”标题；
- `LiurenTianJiang(p)` 调用；
- `LiurenPage` 中对应导入。

确认 `LiurenTianJiang.kt` 已无其他引用后删除该旧组件，避免保留未使用的重复展示实现。

## 边界与错误处理

`LiuRenPlate` 由计算器构建，正常情况下应始终包含十二个天将落位。方盘组件按以下不变量工作：

- 十二个地盘支各绘制一次；
- 每个地盘位对应唯一一个天盘支；
- 每个地盘位对应唯一一个天将。

UI 查找天将时不按天盘支或 `TianJiang` 枚举顺序推测位置，必须使用 `TianJiangOnPlate.earthBranch`。若开发期数据违反唯一落宫不变量，应尽早暴露错误，而不是静默显示错误天将。

伏吟和返吟不需要特殊 UI 分支：

- 伏吟由 `heavenAt()` 自然呈现天地盘重合；
- 返吟由 `heavenAt()` 自然呈现天地盘对冲。

## 测试与验收

### 自动验证

- 保留并运行现有 `LiuRenCalculatorTest`，确保天盘偏移和天将落位算法不回归；
- 将方盘固定方位顺序或盘格描述提取为可测试的内部数据结构；
- 测试外围十二地盘支不缺失、不重复；
- 用已知课盘验证每宫天盘支等于 `plate.heavenAt(earthBranch)`；
- 验证天将按 `earthBranch` 进入正确宫位；
- 验证伏吟天地盘重合、返吟天地盘相冲的数据映射。

### 真机验收

- 起一个普通课，确认每宫同时显示地盘、天盘和天将；
- 起伏吟课与返吟课，目视确认重合及对冲关系；
- 确认方位为上南下北；
- 确认窄屏下无文字截断、宫格重叠或横向溢出；
- 确认原“十二天将所临”标签列表已经删除；
- 确认四课、三传和毕法赋仍正常显示。

## 非目标

本次不修改：

- 月将与占时算法；
- 天盘旋转规则；
- 天将起贵、昼夜及顺逆规则；
- 四课、三传和毕法赋算法；
- 六壬输入项与页面导航。
