# 太乙神数 · 阳九百六（P4-d）设计

> 日期：2026-07-26。范围：卷七「推太岁有阳九之灾法」「推太乙有百六之厄法」两灾厄周期入盘，基星区追加两行。
> 依据：Kanripo KR3g0047_007（卷七）逐字核对；原文自带例锚定（618/162/354/642，跨 2500 年全合）。

## 1. 原文与公式

积年锚：演纪上元甲寅，开元十二年（724）积 13,331 年 → `J = year + 12607`（与五福同锚），`u = J − 1`。

**阳九**（「该四千五百六十为一元，四百五十六岁为一阳九；十三年移一邦，命起寅邦顺行十二邦」）：
- 元 = `u / 4560 + 1`；元内第 N 阳九 = `(u / 456) % 10 + 1`；入第 X 年 = `u % 456 + 1`
- 邦 = 寅 + `(u % 156) / 13`（13 年/邦；156 与跨度 456 不整除，原文如此，存疑标注）
- 验证：618→元3 第十 第1年 ✓（原文「入第十阳九」）；162→第九 ✓；周平王二十年(-750)→第七 ✓；1074→元4 第一 第1年（原文「开元十二年以后三百五十年方会」反推 ✓）

**百六**（「二百八十八年为一周，十五周为一元共计四千三百二十；二十四年移一邦，命起寅邦」）：
- 元 = `u / 4320 − 1`（卷七口径：元1 起 J=8641；354 入第二元一百六、642 入第二百六反推坐实）
- 元内第 N 百六 = `(u / 288) % 15 + 1`；入第 X 年 = `u % 288 + 1`；邦 = 寅 + `(u % 288) / 24`
- 验证：354→元2 第一 第1年·寅邦 ✓；642→元2 第二 第1年·寅邦 ✓；汉明帝永平九年(66)→元1 第十五 ✓

**警示**（注记追加，非格局）：入第 1 年 →「值会」；邦支冲太岁支（六冲）→「冲太岁」（原文「或与太岁冲并于分野」的简化实现，注明）。
