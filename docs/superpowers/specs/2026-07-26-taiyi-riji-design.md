# 太乙神数 · 日计入局设计

> 日期：2026-07-26。范围：四计之三「日计」入局 + 八将 + 卷四星宿（金镜起戌口径，分群锚定）。
> 依据：《太乙金镜式经》卷一（ctext chapter=582866）Image 44/48/42 原文核定；用户实盘锚 2026-07-26/27/28 三日验证。
> 状态：八将 + 全部星宿（四神组/三基组/大游/五福/小游）已五日实盘逐项验证 ✅（07-26/27/28/08-18/10-29）。

## 0. 背景与硬约束破解

- 现状：`computeJu` 第 395-396 行 `MONTH/DAY → TODO("月计/日计入局待实现")`。年计/时计已上线。
- memory 曾标记硬伤：「日计积日须以章岁657/章月8726/月法2447/日法49 农历差法推，app 无农历基础设施」。
- **破解**：积日是连续日数（每日 +1），故 `积日(D) = 儒略日(D) + 常数C`，与原文农历差法在**所有日期上数学等价**（只差一个被 mod 吸收的常数）。无需建农历层。
- 整个日计盘面仅由 `积日 mod 72` + 日支(太岁) 决定（72=3×24=4×18，故 mod 72 唯一确定太乙宫/文昌/局）。

## 1. 原文依据（卷一）

- **Image 44 推日计太乙所在**：`积日 mod 360 → mod 72 → mod 24 → ÷3 为宫数`，与年计(Image 8)、月计(Image 33)**完全同法**。
- **Image 48 推日计计神**：`积日 mod 60 → ÷12，命起寅逆行`——等价于本项目「日支查表」法（reference §6 已证四计统一）。
- **Image 42 推积日**：积月 × 月法2447 ÷ 日法49 = 积日（农历链，本项目以 JD 等价替代）。
- **Image 42 算例**：梁天监三年(504)六月八日「太乙在八宫，和德为天目」；其积日数字「707,050,061」与盘面反推矛盾 → **刻本/传抄讹**，仅口述实盘可信。
- **日计恒阳遁**（reference §0）。
- **八门原文阙**：卷一 Image 101-109 只载时计/岁计八门，日计/月计八门阙如。

## 2. 入局算法（核心）

```
suanBase(日计) = dt.toLocalDate().toEpochDay() + C
  // toEpochDay = 自 1970-01-01 的公历连续日数，每日 +1 ⇒ 等价原文积日
  // C 锚定：floorMod(suanBase, 72) = 49 ⇔ juNo = 50（用户锚 2026-07-26=阳遁50局）
dun = TaiyiDun.YANG                    // 日计恒阳遁
太岁 = bazi.dayPillar.branch            // 日支（taiSuiBranch 已支持 DAY）
```

**C 推导**：`toEpochDay(2026-07-26) = 20660`；`20660 mod 72 = 68`；`(68 + C) mod 72 = 49 ⇒ C ≡ 53 (mod 72)`，取 **C = 53**。
验证：07-26→50局、07-27→51局、07-28→52局（逐日 +1 ✅）；太乙 1宫乾(阴德)→1宫乾→**2宫离(大威)**（3日一移 ✅）。

太乙落宫/文昌/局号全部复用 `computeJu` 现有逻辑，零改动。

## 4. 卷四星宿（金镜起戌口径，分群锚定）

用户决策：日计排星宿，金镜卷四口径（三基**起戌**）。经 07-26/27/28 三日实盘核定，日计星宿**按群用不同积日锚**（同年计各星宿有各自上元锚，非 bug）：

| 群 | 成员 | 日计锚 | 五日验证 |
|---|---|---|---|
| 四神组 | 四神/天乙/地乙/直符 + 民基(mod12) + **大游** | `suanBase`（K=53） | ✅ |
| 三基组 | 臣基/君基（民基 mod12 不敏感，同属） | `suanBase + 24`（K=77） | ✅ |
| 五福 | — | `suanBase + 200`（C5∈[190,207]） | ✅（0818 乾/1029 艮） |
| 小游 | — | = 太乙宫 | ✅ |

**四日星宿验证**（`suanBase`：07-26=20713 / 07-27=20714 / 07-28=20715 / 08-18=20736）：
- 四神组（step=`suanBase mod36 ÷3`，4→4→5→0）：地乙 阴德→阴德→大威→大炅 ✅；四神 …→太簇→阴德 ✅；天乙 …→大簇 ✅；民基 亥→子→丑→阴主(戌) ✅。
- 三基组（base=`suanBase+24`，起戌）：臣基 戌→戌→亥→大威(午) ✅；君基 巳→巳→巳→大威(午) ✅。
- 大游（`seq[(suanBase mod288)/36]`，起七宫序[7,8,9,1,2,3,4,6]）：…→地主(8宫,07-28 软件值存疑)→**大武(7宫,08-18)** ✅。
- 五福（`((suanBase mod225)-1)/45`，序乾艮巽坤中）：…→大炅(巽,07-26/28 软件值存疑)→**阴德(乾1,08-18)** ✅。
- 小游：阴德→阴德→大威→阴德（同太乙宫）✅。

> ⚠ 07-26/28 参考软件的 五福=巽、大游=8宫 与 08-18 的 五福=乾、大游=7宫 自相矛盾（五福 45 日一宫、23 天内不可能巽→乾）。判定 07-26/28 那两值系软件 bug，**08-18 干净盘面为权威**：大游/五福 = `suanBase`。

实现：`computeJiXing` 增加 `suanBase`（积日-1）与 `countType`；日计分支：
- 四神组：`step = floorMod(suanBase, 36) / 3`（base=suanBase）。
- 三基组：`ruZhou = floorMod(suanBase + 24, 360)`，起戌(10)；臣基 `mod36÷3`、民基 `mod12`、君基 `/30`。
- 大游：`seq[floorMod(suanBase, 288) / 36]`，起七宫。
- 五福：`gong = (floorMod(suanBase + 200, 225) - 1) / 45`，序[乾,艮,巽,坤,中]（C5=200，范围[190,207]——0818/1029 两跨宫日钉定；窄于 45 日周期，实用可靠）。
- 小游：太乙宫。
- 飞符：不排（卷五无）。阳九百六：日计不排（年灾厄）。
