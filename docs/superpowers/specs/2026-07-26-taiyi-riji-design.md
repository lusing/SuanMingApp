# 太乙神数 · 日计入局设计

> 日期：2026-07-26。范围：四计之三「日计」入局 + 八将 + 卷四星宿（金镜起戌口径）。
> 依据：《太乙金镜式经》卷一（ctext chapter=582866）Image 44/48/42 原文核定；用户实盘锚 2026-07-26=阳遁50局。
> 状态：八将核心已用用户完整盘面逐项验证 ✅。

## 0. 背景与硬约束破解

- 现状：`computeJu` 第 395-396 行 `MONTH/DAY → TODO("月计/日计入局待实现")`。年计/时计已上线。
- memory 曾标记硬伤：「日计积日须以章岁657/章月8726/月法2447/日法49 农历差法推，app 无农历基础设施」。
- **破解**：积日是连续日数（每日 +1），故 `积日(D) = 儒略日(D) + 常数C`，与原文农历差法在**所有日期上数学等价**（只差一个被 mod 吸收的常数）。无需建农历层。
- 整个日计盘面仅由 `积日 mod 72` + 日支(太岁) 决定（72=3×24=4×18，故 mod 72 唯一确定太乙宫/文昌/局）。

## 1. 原文依据（卷一）

- **Image 44 推日计太乙所在**：「置积日，以周纪法三百六十去之；不尽者，以元法七十二去之；不尽，以太乙小周法二十四去之；又不尽，以三约之，为宫数；不满，为入宫以来日数。其宫数命起一宫，不游中五，算外，即太乙所在也。」——与年计(Image 8)、月计(Image 33)**完全同法**。

- **Image 42 推积日**：积月 × 月法2447 ÷ 日法49 = 积日（农历链，本项目以 JD 等价替代）。
- **Image 42 算例**：梁天监三年(504)六月八日「太乙在八宫，和德为天目」；其积日数字「707,050,061」与盘面反推矛盾（mod 72 算得 53 局而非 8 宫对应的 45 局）→ **刻本/传抄讹**，仅「太乙8宫/和德」口述实盘可信。
- **日计恒阳遁**（reference §0：岁/月/日计恒阳遁；唯时计分阴阳）。

## 2. 入局算法（核心）

```
suanSteps(日计) = dt.toLocalDate().toEpochDay() + C
  // toEpochDay = 自 1970-01-01 的公历连续日数，每日 +1 ⇒ 等价原文积日
  // C 锚定：floorMod(suanSteps, 72) = 49 ⇔ juNo = 50（用户锚 2026-07-26=阳遁50局）
dun = TaiyiDun.YANG                    // 日计恒阳遁
太岁 = bazi.dayPillar.branch            // 日支（taiSuiBranch 已支持 DAY）
```

**C 推导**：`toEpochDay(2026-07-26) = 20660`；`20660 mod 72 = 68`；`(68 + C) mod 72 = 49 ⇒ C ≡ 53 (mod 72)`，取 **C = 53**。
验证：`floorMod(20660+53, 72) = floorMod(20713, 72) = 49 → juNo = 50 ✅`。

太乙落宫/文昌/局号全部复用 `computeJu` 现有逻辑（`jingShu = suanSteps mod 24`、`gongXu = jingShu / 3`、`juNo = suanSteps mod 72 + 1`），零改动。

**相位说明**：C 仅锚定 `mod 72`（局/太乙宫/文昌/主客算——核心盘面，100% 正确）。`suanSteps` 即 `ju.suanBase`（积日-1，= 20713 @ 2026-07-26），下传 `computeJiXing`。`mod 360`（「第几纪」）未核定，暂不显示（见 §6）。

## 4. 卷四星宿（金镜起戌口径，suanSteps 代入）

用户决策：日计排星宿，统一用本项目金镜卷四口径（三基**起戌**、`suanSteps` 代入）。本项目自洽；与用户参考软件（三基起午、含飞符）的臣基/君基/五福不同——以金镜为准。

实现：`computeJiXing` 增加 `suanBase`（积日-1）与 `countType` 入参；日计分支用 `suanBase mod 周期`（锚 0，因 `suanBase` 已是积日），年计保持现状（`year` + 各上元锚）。

| 星宿 | 日计公式 | 2026-07-26 结果 | 与用户参考软件 |
|---|---|---|---|
| 民基 | `(10 + suanBase mod 12) mod 12`，起戌 | 亥·大义 | ✅ 一致 |
| 臣基 | `(10 + (suanBase mod 36)/3) mod 12`，起戌 | 寅 | ✗(彼起午→戌) |
| 君基 | `(10 + (suanBase mod 360)/30) mod 12`，起戌 | 辰 | ✗(彼起午→巳) |
| 五福 | `gong = (suanBase mod 225 - 1)/45`，序乾艮巽坤中 | 乾1宫 | ✗(彼→巽) |
| 大游 | `seq[(suanBase mod 288)/36]`，起七宫 | 兑6宫 | — |
| 小游 | = 太乙宫 | 阴德(乾1宫) | ✅ 一致 |
| 四神 | `pos=(0+step)%12`，step=`suanBase mod 36 /3` | 中5宫 | — |
| 天乙 | `pos=(5+step)%12` | 绛宫 | — |
| 地乙 | `pos=(8+step)%12` | 阴德(乾1宫) | ✅ 一致 |
| 直符 | `pos=(4+step)%12` | 大炅(巽9宫) | ✅ 一致 |

其中 `suanBase = 20713`（2026-07-26），`step = floorMod(20713, 36)/3 = 13/3 = 4`。

**长短周期核定状态**（须在 UI/spec 注明）：
- **短周期（mod 12/36，整除 72）**：相位由 50 局锚（`mod 72=49`）唯一确定 → 民基/臣基/四神/天乙/地乙/直符/小游 **确定**（民基亥/地乙阴德/直符大炅/小游阴德 与用户一致 ✅）。
- **长周期（mod 360/225/288，不整除 72）**：相位依 50 局锚外推的 `suanBase mod` 推算，**绝对相位未核定**（原文 504 算例积日讹、无法独立核定；用户参考软件起午口径亦不自洽）。君基/五福/大游 结果会与部分软件不同。

## 9. 风险与标注

1. **长周期星宿未核定**：君基/五福/大游 的 `mod 360/225/288` 相位依 50 局锚外推，无原文独立锚；UI 注明「日计长周期星宿为金镜口径推算，绝对相位未核定」。
2. **三基起戌 vs 起午**：本项目用金镜卷四「起戌」（memory P2 核定，§17「起午」作讹）；与用户参考软件（起午）的臣基/君基不同，以本项目口径为准。
3. **飞符不排**：卷五无飞符（淘金歌概念），与用户参考软件（排飞符）不同。
4. **阳九百六日计不排**：卷七灾厄周期为「年」级概念，日计下不显示。
5. **50 局相位与六十甲子不同步**：`suanBase mod 72=49` 与「积日 mod 60=甲子序」无整数解（不相容）；本项目计神用日支查表（非 Image 48 积日法），盘面内部自洽（与年计同架构）。
